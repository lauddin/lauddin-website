LAUDDIN Personal Website

FILES
- index.html: website structure and content
- style.css: design and responsive layout
- script.js: language switcher and mobile menu
- profile.jpg: add your own portrait photo using this exact filename

HOW TO PREVIEW
1. Keep all files in the same folder.
2. Open index.html in a web browser.
3. To add your portrait, copy your image into this folder and rename it profile.jpg.

HOW TO PUBLISH FOR FREE
You can publish this static website using GitHub Pages or Netlify. Upload the files
(with profile.jpg if desired) and follow the host's publish instructions.

CUSTOMIZATION
Edit the text in index.html. Update colors and layout in style.css.
